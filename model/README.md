# Body model

`body.bin` and `body.json` (format v3) are generated by `build_v3.py`, an original procedural figure
built from signed distance shapes. No third-party models or artwork are used.

Each muscle is its own shape. The surface is shaded darker where two muscle shapes meet, which gives the
dark seam lines. Each body region (chest, abs, quads and so on) is a separate mesh, so the app can tint
regions for training load and soreness.
