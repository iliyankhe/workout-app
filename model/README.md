# Body model

`body.bin` and `body.json` are a muscle model taken from **Z-Anatomy** (Gauthier Kervyn, Marcin Zielinski and contributors),
licensed under **Creative Commons Attribution-ShareAlike 4.0** (CC BY-SA 4.0): https://creativecommons.org/licenses/by-sa/4.0/

Z-Anatomy is based on BodyParts3D (Database Center for Life Science, Japan). Changes made here: muscles were selected,
grouped into body regions, decimated to about 15% of their triangles on large muscles, and exported to a
binary file for the web. The model files are shared under the same CC BY-SA 4.0 licence.
